# Sózdik 3000 — тренажёр английских слов

Бесплатный тренажёр для изучения 3000+ самых важных английских слов с переводом
на **казахский** и **русский** языки. Работает в любом браузере, устанавливается
на телефон как приложение (PWA) и полностью работает офлайн.

## Возможности

- **4 режима тренировки**: флеш-карточки, тест с 4 вариантами, ввод перевода, повторение
- **Интервальное повторение (SRS)** по системе Лейтнера: правильный ответ
  отодвигает следующий показ слова (1 → 3 → 7 → 14 → 30 дней), ошибка
  возвращает слово в начало
- **Дневная цель** (10/20/50/100 слов) с прогресс-баром и празднованием 🎉
- **Стрик** — счётчик дней подряд с выученными словами (день засчитывается
  только за реально выученные слова)
- **Фильтры** по уровням CEFR (A1–B2) и 12 тематическим категориям
- **Два языка интерфейса**: казахский (по умолчанию) и русский
- **Озвучка** английских слов (Web Speech API)
- **График прогресса** — новые слова по дням за неделю
- **Экспорт/импорт прогресса** в JSON-файл — перенос между устройствами без аккаунта
- **Клавиатура**: Space — перевернуть карточку, 1/2 — «не знал»/«знал»,
  1–4 — варианты теста, Enter/стрелки — навигация
- **Офлайн-режим** — service worker кэширует приложение целиком

## Запуск

Это статический сайт без сборки — достаточно открыть `index.html` в браузере.

Для полноценной работы PWA (офлайн, установка) нужен HTTP-сервер:

```bash
npx http-server -p 8080
# открыть http://localhost:8080
```

Деплоить можно на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `app.js` | Вся логика: режимы, SRS, статистика, локализация |
| `data.js` | Словарь: `[слово, часть речи, уровень, перевод kz, перевод ru, категория]` |
| `style.css` | Стили (тёмная тема) |
| `sw.js` | Service worker (офлайн-кэш) |
| `manifest.json` | Манифест PWA |
| `tools/` | Скрипты проверки данных и тесты |

## Проверки и тесты

```bash
# Валидация словаря (структура, артефакты перевода, дубликаты)
node tools/validate-data.js

# Смоук-тест приложения в headless Chromium (36 проверок)
node tools/smoke-test.js   # требуется playwright и установленный chromium
```

Прогоняйте обе проверки перед каждым релизом. При изменении любого файла
приложения не забудьте поднять версию кэша в `sw.js` (`sozdik3000-v2` → `v3`),
иначе пользователи с установленным PWA не получат обновление.

## Хранение данных

Весь прогресс хранится локально в `localStorage`:

- `ox_progress` — состояние SRS: `{v: 2, srs: {слово: {box, due}}}`
- `ox_history` — история по дням: `[{date, known, learned}]`
- `ox_settings` — язык, звук, таймер, дневная цель

Старый формат прогресса (`{known: [], repeat: []}`) мигрирует автоматически.

## Происхождение данных

Словарь — 3000+ самых важных английских слов по уровням CEFR (A1–B2)
с переводами на казахский и русский. Для полной лицензионной чистоты
в перспективе рекомендуется перевести базу на
[NGSL (New General Service List)](https://www.newgeneralservicelist.com/) —
научно составленный список ~2800 самых частотных слов под открытой
лицензией CC BY 4.0.
